Conditionals (Alex)

Introduction

Conditionals, or conditional statements, allow a program to ask questions and decide which code to execute based on the answers. They represent "forks in the road" within your code's logic.

Comparison Operators

Python includes built-in syntax for asking mathematical questions:

> Greater than >= Greater than or equal to < Less than <= Less than or equal to == Equal to (Equality comparison) != Not equal to
Important: Note the difference between = and ==. A single equals sign = is for assignment (setting a variable), while a double equals sign == is for comparison.

The if Statement

The if statement is the most basic conditional keyword. If a Boolean expression (a question with a True/False answer) evaluates to True, the indented code block below it executes.

Example: compare.py

x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")
if x > y:
    print("x is greater than y")
if x == y:
    print("x is equal to y")

Syntax Rules

  • Colons: Every if statement must end with a colon (:).
  • Indentation: The code to be executed under the condition must be indented (typically 4 spaces or 1 tab). Python enforces this strictly.

Improving Design with elif and else

In the example above, the program asks three separate questions even if the first one is already answered. This is inefficient. We can use elif (else if) and else to create mutually exclusive conditions.

The elif Keyword

Using elif ensures that if the first condition is True, the program skips the remaining checks. This optimizes the control flow.

The else Keyword

If all previous if and elif conditions are False, the else block serves as a "catch-all" without needing an explicit question.

if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
else:
    print("x is equal to y")

Logical Operators: or and and

You can combine multiple questions into a single statement using logical operators.

Using or

An or statement is True if at least one of the conditions is True.

if x < y or x > y:
    print("x is not equal to y")
else:
    print("x is equal to y")

Using and

An and statement is True only if both conditions are True.

if score >= 90 and score <= 100:
    print("Grade: A")

Advanced Syntax: Chaining Comparisons

Python allows for a more concise way to check ranges, similar to mathematical notation:

if 90 <= score <= 100:
    print("Grade: A")
elif 80 <= score < 90:
    print("Grade: B")

This "chains" the comparisons, making the code easier to read and faster to type.

Optimization Refinement

By logically ordering your checks, you can simplify conditions even further. For a grading system, if you check for the highest grade first, you don't need to check the upper bound in subsequent steps because those scores have already been "caught" by previous blocks.

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
