Conditionals (Riley)

Note
"Conditionals allow you to take the proverbial forks in the road within your own code logically."

What Are Conditionals?

  • Conditionals are statements that ask questions in your code.
  • These questions have true or false answers, allowing the program to choose which lines of code to execute.
  • They help direct the control flow of the program based on decisions.

Comparison Operators in Python

Python uses special symbols (operators) to compare values. These operators are the foundation of questions asked in conditionals.

Operator Meaning Notes
> Greater than Checks if left value is greater than right value
>= Greater than or equal Typed as two characters (>=) on the keyboard
< Less than Checks if left value is less than right value
<= Less than or equal Typed as two characters (<=) on the keyboard
== Equals (equality) Checks if left value equals right value; different from assignment
!= Not equal Checks if left value is not equal to right value
Caution
Important: Single equals sign = is assignment, not equality comparison.

Using if Statements in Python

  • The keyword if introduces a conditional statement.
  • Syntax requires a Boolean expression (a question that evaluates to True or False) after if.
  • Followed by a colon : and an indented block of code that runs only if the condition is True.

Example

if x < y:
    print("x is less than y")
  • Indentation (4 spaces or one tab) signals that the indented code belongs to the if statement.
  • Parentheses around the condition are optional in Python for simple conditions.
  • The Boolean expression here is x < y.

Boolean Expressions

Note
"A Boolean expression is simply a question that has a yes or no answer, or technically a true or false answer."
  • Boolean expressions use the comparison operators.
  • They decide the control flow: if true, execute the indented code; if false, skip it.

Example Program: Comparing Two Integers

This program compares two integers entered by the user and prints which one is larger or if they are equal.

x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")

if x > y:
    print("x is greater than y")

if x == y:
    print("x is equal to y")
  • input() gets a string from the user.
  • int() converts the input to an integer.
  • Three separate if statements check all possibilities.

Control Flow Visualized: Flow Chart

  • The program's logic can be visualized as a flow chart representing control flow.
  • Start → Question 1 (x < y?) → If true, print "x is less than y" → Continue
  • Question 2 (x > y?) → If true, print "x is greater than y" → Continue
  • Question 3 (x == y?) → If true, print "x is equal to y" → End
  • Each question is a diamond shape in the flow chart representing a decision point.
  • Arrows labeled true or false dictate the path to follow.

Critique of the Example Program

  • The program is correct but not well designed.
  • It asks all three questions every time, even if one condition already determined the answer.
  • This leads to repetitive and inefficient code.

Improving Conditionals with elif

  • elif stands for "else if" and allows you to chain conditions more logically.
  • When using elif, once a true condition is found, the rest are skipped.
  • This avoids unnecessary checks and makes code more concise.

Conceptual Usage of elif

if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
else:
    print("x is equal to y")
  • Here, if x < y is true, Python skips the elif and else.
  • If x < y is false but x > y is true, it executes the elif block.
  • If neither condition is true, it falls back to the else block.

Improving Conditional Logic with if, elif, else

Note
"Instead of asking multiple if questions independently, we can use mutually exclusive conditions with elif and else to ask fewer questions and write clearer, more efficient code."

Using if, elif, and else Instead of Multiple ifs

  • Original approach: Multiple if statements check all conditions regardless of earlier true answers.
  • Improved approach: Use if followed by elif (else if) and then optionally else to make conditions mutually exclusive.
  • Benefit: Once a condition is true, Python skips the remaining conditions, asking fewer questions.

Logical Flow in the Improved Program

Step Condition Tested Outcome if True Next Step if False
1 x < y Print "x is less than y" and stop Check x > y
2 x > y Print "x is greater than y" and stop Check x == y
3 x == y Print "x is equal to y" and stop (Optionally handle false case, but logically unnecessary)
  • Example:
    • Input: x=1, y=2 → Only first condition true, program stops after first question.
    • Input: x=2, y=1 → First condition false, second true, program stops after second question.
    • Input: x=1, y=1 → First two false, third true.

Flowchart Representation

  • Using if, elif, elif:
    • The program may ask 1, 2, or 3 questions depending on inputs.
  • Using if, elif, else:
    • Eliminates the need to check x == y explicitly because it is the only remaining option after the first two conditions fail.

Replacing the Final elif with else

  • Code before: Using elif x == y:
  • Code after (using else): Using else:
  • Why? If neither x < y nor x > y is true, x must be equal to y logically, so no need to explicitly check x == y.

Advantages of Using else at the End

Aspect Using elif x == y Using else
Number of conditions 3 2
Code complexity Higher Lower
Readability Slightly harder Easier to read and maintain
Logical clarity Explicit check Logically implied default case
Potential for mistakes Slightly higher (more code) Lower (simpler control flow)

Using or to Combine Conditions

  • You can combine multiple conditions into one using the or keyword.
  • Example: Checking if x is not equal to y.
  • Logic: If x is either less than or greater than y, it is not equal to y. Otherwise, it must be equal.

Explanation of Code Behavior Using Metaphor

Note
Imagine you are asking a series of questions to identify a person's favorite fruit. Once you know the answer is "apple," you stop asking any more questions. If it's not "apple," you ask if it's "banana," and if not, you ask if it's "cherry." Finally, if all these are false, you conclude it must be "date" without asking explicitly. This saves time and effort by avoiding unnecessary questions. Similarly, if, elif, and else help the program stop asking conditions once an answer is found.

Important Takeaways

  • Use if → elif → else for mutually exclusive conditions to reduce the number of questions asked.
  • Use else as a catchall to simplify logic when all other cases are excluded.
  • Use or to combine multiple checks into a single conditional expression.
  • These strategies improve code readability, efficiency, and maintainability.

Comparing Two Values: Simplifying Conditions

The lecture discussed how to compare two variables, x and y, to determine if they are equal or not, and how to simplify the code and flowcharts for these comparisons.

Scenario Logic Description Code Logic Example
Check if x < y If true, print "x is not equal to y" and stop if x < y: print("x is not equal to y")
Check if x > y If true, print "x is not equal to y" and stop elif x > y: print("x is not equal to y")
Otherwise (x == y) Print "x is equal to y" and stop else: print("x is equal to y")
  • The code can be simplified by avoiding unnecessary repeated checks.
  • Instead of checking both x < y and x > y, use a single condition to check if x != y (not equal).
  • If x != y is false, it implies x == y.

Simplified Conditional Example

if x != y:
    print("x is not equal to y")
else:
    print("x is equal to y")
  • This approach reduces the number of questions asked by the program to just one.
  • The flowchart of this logic is simpler, with only one decision diamond.

Alternative: Checking Equality First

You can invert the logic by checking equality first:

if x == y:
    print("x is equal to y")
else:
    print("x is not equal to y")
  • In this case, the print statements are swapped.
  • The program still asks only one question, focusing on either equality or inequality.

Using Chained Comparisons in Python

Python allows chaining comparisons like on paper, which makes code cleaner:

if 90 <= score <= 100:
    print("A")
elif 80 <= score < 90:
    print("B")
elif 70 <= score < 80:
    print("C")
elif 60 <= score < 70:
    print("D")
else:
    print("F")
  • This chained comparison is equivalent to combining two Boolean expressions with and.
  • It reduces redundancy and improves readability.

Optimizing Conditional Logic for Grade Assignment

Note
"Simplifying conditional checks not only makes the code shorter but also improves readability and maintainability."

Initial Approach: Two-Question Checks Per Grade Range

  • Original logic asked two questions for each grade range:
    • Example for A: Is score > 90 and score < 100?
    • Example for B: Is score > 80 and score < 90?
  • This approach, while explicit, is verbose and repetitive.

Improved Approach: Single-Condition Checks Using if-elif-else

  • Assumption: Input scores are between 0 and 100.
  • Logic structure:
Condition Grade
If score ≥ 90 A
Else if score ≥ 80 B
Else if score ≥ 70 C
Else if score ≥ 60 D
Else F
  • Key insight: Because of the if-elif-else structure, each condition implicitly assumes the previous conditions are false.
  • For example, when checking score ≥ 80, we already know score < 90 because the first if failed.
  • This reduces the number of questions asked, minimizing redundant checks.

Benefits of the Optimized Logic

Aspect Explanation
Succinctness Fewer conditions per grade range; more compact code.
Readability Easier to follow logic flow since each condition is a single, clear check without double bounds.
Maintainability Less code means fewer places for bugs; the logic is easier to update and understand over time.

Summary of Logic Flow

  • The if-elif-else chain works by short-circuiting:
    • Once a condition is met, the rest are skipped.
  • This means each condition implicitly narrows the score range without explicitly checking both upper and lower bounds.

This method is a minor optimization but a good example of writing cleaner, more efficient conditional statements by leveraging the structure of control flow statements.
